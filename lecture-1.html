📘 الملخص المكثف

المحاور الأساسية للمحاضرة

① مفهوم الشبكة وأنواعها الأساسية② المكونات الأساسية للشبكة③ أجهزة ربط الشبكة④ نموذج TCP/IP وآلية التغليف (Encapsulation)

①مفهوم الشبكة وأنواعها الأساسية

  • تعريف الشبكة (Network): جهازا كمبيوتر أو أكثر متصلان معاً لمشاركة الموارد (البيانات، التطبيقات، الطابعات، والإنترنت)، ويتخاطبان بلغة النظام الثنائي (Binary Code: 0 و 1).
  • الشبكة المحلية (LAN - Local Area Network): تغطي منطقة جغرافية محدودة (مكتب، قسم، أو مبنى). يُفضل تقسيم شبكات LAN الكبيرة إلى مجموعات عمل أصغر لتسهيل الإدارة ورفع مستوى الأمان.
  • مجموعة العمل (Workgroup): مجموعة أجهزة تعمل في نفس النطاق أو القسم داخل شبكة LAN (مثل قسم المحاسبة أو التسويق) دون ارتباط أمني خاص بينها.
  • الشبكة الواسعة (WAN - Wide Area Network): تغطي منطقة جغرافية واسعة وتربط عدة شبكات محلية معاً باستخدام عناوين IP وأجهزة التوجيه (Routers)، وأبرز مثال عليها شبكة الإنترنت.

②المكونات الأساسية للشبكة

  • جهاز الحاسب (Host / Workstation / Client):
    • Host: أي جهاز متصل بالشبكة يمتلك عنوان IP.
    • Client: أي جهاز يطلب الخدمة من السيرفر.
  • الخادم (Server): حاسب بمواصفات عالية يخدم الأجهزة الأخرى ويدير موارد الشبكة، ويجب تأمينه بالنسخ الاحتياطي وأجهزة بديلة لضمان استمرارية الخدمة. أبرز أنواعه:
    • File Server: حفظ وتوزيع الملفات.
    • Mail Server: إدارة البريد الإلكتروني.
    • Print Server: التحكم بالطابعات المشتركة على الشبكة.
    • Web Server: استضافة مواقع وصفحات الويب وتوزيع محتواها.
    • Fax Server: إرسال واستقبال رسائل الفاكس الإلكترونية.
    • Application Server: إدارة تطبيقات الشبكة.
    • Telephony Server: إدارة مراكز الاتصال وتوجيه المكالمات.
    • Proxy Server: يتولى المهام نيابةً عن الأجهزة الأخرى (خصوصاً الاتصال بالإنترنت).

③أجهزة ربط الشبكة

الجهاز الطبقة / العنوان المعتمد الوظيفة والخصائص الأساسية للامتحان
كرت الشبكة (NIC) يرتبط بعنوان فيزيائي MAC Address يربط الحاسب بالشبكة سلكياً أو لاسلكياً بسرعة 10 / 100 / 1000 Mbps. في اختبارات اختراق الـ Wi-Fi نحتاج كرتاً خارجياً يدعم Monitor Mode وحقن الفريمات (Packet Injection).
الموزع (Hub) الطبقة الأولى (غير ذكي) يربط الأجهزة ببنية نجمية ويكرر الإشارة لكل المنافذ عدا منفذ المصدر. يشكل منطقة تصادم واحدة (Single Collision Domain) ويعتمد على آلية CSMA/CD، ويفتقر للسرية ويستهلك عرض الحزمة (Bandwidth).
الجسر (Bridge) الطبقة الثانية (MAC Address) يربط جزأين من الشبكة ويفصل حركة البيانات بينهما لتقسيم الشبكة إلى مناطق تصادم أصغر.
المبدل (Switch) الطبقة الثانية (MAC Address) جهاز ذكي يوجه الرسالة فقط إلى منفذ الجهاز الهدف بناءً على عنوان MAC. كل منفذ فيه يعتبر منطقة تصادم منفصلة (Separate Collision Domain) ويدعم الإرسال والاستقبال بنفس الوقت.
الموجه (Router) الطبقة الثالثة (IP Address) يربط الشبكات المختلفة معاً (مثل ربط LAN مع WAN أو فصل مجموعات العمل إدارياً وأمنياً) ويختار أفضل مسار. يدعم ميزات مراقبة وحماية مثل Cisco NetFlow وقوائم التحكم بالوصول (ACLs) وشبكات VPN وبروتوكول المصادقة 802.1x.

④نموذج TCP/IP وآلية التغليف (Encapsulation)

  • مبادئ عمل الطبقات:
    • في نفس الجهاز: كل طبقة تقدم خدمات للطبقة الأعلى منها.
    • بين جهازين مختلفين: تتخاطب الطبقات المتناظرة باستخدام نفس البروتوكول.
طبقة TCP/IP اسم وحدة البيانات (PDU) البروتوكولات العاملة في الطبقة الوظيفة الجوهرية
Application Layer Application data HTTP, SMTP, FTP واجهة التطبيقات التي يتعامل معها المستخدم (تصفح الويب، البريد، نقل الملفات).
Transport Layer Segment TCP, UDP ضمان/إدارة تسليم البيانات وتحديد الخدمة عبر أرقام المنافذ (Ports، مثل 80 للويب و21 لـ FTP).
Internet Layer (IP/Network) Packet IP العنونة المنطقية (IP Address) وتوجيه الحزم عبر القفزات والعقد (Nodes / Routers).
Link Layer (Physical + Data Link) Frame (وفي الفيزيائية Bit) Ethernet, Point-to-Point (PPP), PPPoA التغليف الفيزيائي والعنونة الفيزيائية وإرسال البتات عبر وسط الاتصال وكرت الشبكة (NIC).
  • التغليف وفك التغليف (Encapsulation & Decapsulation):
    • عند الإرسال (Encapsulation): تنتقل البيانات من الأعلى للأسفل؛ تضيف كل طبقة ترويسة خاصة بها (Header) وتضيف طبقة الربط ترويسة وتذييلاً (Header & Trailer) لتشكيل الـ Frame.
    • عند الاستقبال (Decapsulation): تنتقل البيانات من الأسفل للأعلى؛ تقرأ كل طبقة ترويستها وتزيلها ثم تمرر الحمولة (Payload) للطبقة الأعلى.
    • ملاحظة مهمة حول عمل الراوتر في المسار: الراوتر يفك تغليف طبقة Link Layer (Frame) ليقرأ عنوان الهدف في ترويسة IP Packet ويوجهها للقفزة التالية، ثم يعيد تغليفها في Frame جديد يناسب وسط النقل التالي (مثل Ethernet أو PPPoA)، ولا يصعد لطبقات Transport أو Application.
