المحاور الأساسية للمحاضرة

① نظام أسماء النطاقات (DNS - Domain Name System)② بروتوكول الإصدار السادس (IPv6) ومقارنته الشاملة مع IPv4③ قواعد اختصار عناوين IPv6 والعناوين المحجوزة

①نظام أسماء النطاقات (DNS - Domain Name System)

  • الوظيفة: قاعدة بيانات هرمية موزعة تترجم أسماء النطاقات (Domain Names مثل www.cisco.com) إلى عناوين IP المقابلة لها.
  • ملف Hosts القديم: قبل ظهور DNS كانت الترجمة تتم محلياً عبر ملف hosts الموجود في نظام Windows ضمن المسار: C:\Windows\System32\drivers\etc\hosts
  • المستويات الأربعة للبنية الهرمية في DNS:
    1. Root (.): أعلى مستوى في البنية الهرمية ويُرمز له بنقطة.
    2. Top Level Domains (TLD): اختصارات من حرفين أو ثلاثة تحدد نوع الموقع أو الدولة (مثل .com، .edu، .gov).
    3. Second Level Domains: اسم النطاق الرئيسي وقد يتفرع منه نطاقات فرعية (Subdomains).
    4. Host Names: أسماء الأجهزة أو الخوادم المحددة داخل الشبكة.
  • آلية الاستعلام في DNS: يطلب المستخدم الاسم من سيرفر DNS المحلي ← يسأل Root Server ← يسأل سيرفر TLD ← يصل إلى السيرفر المسؤول عن النطاق (Authoritative DNS Server) الذي يقرأ ملف النطاق ويرد بعنوان الـ IP، وتُحفظ النتيجة مؤقتاً في الكاش (DNS Cache) لتسريع الطلبات اللاحقة.
  • أنواع سجلات DNS الأساسية:
نوع السجل (Record Type) الوظيفة والوصف
A يربط اسم النطاق بعنوان IPv4.
AAAA يربط اسم النطاق بعنوان IPv6.
MX يشير إلى عنوان خادم البريد الإلكتروني (Mail Server).
NS يشير إلى اسم خادم النطاقات (Name Server).
SRV سجلات الخدمة؛ تحوي معلومات عن المنطقة واسم السيرفر المعتمد لخدمة معينة.

②بروتوكول الإصدار السادس (IPv6) ومقارنته الشاملة مع IPv4

صُمم IPv6 كحل جذري طويل الأمد لمشكلة استنزاف عناوين IPv4 وتوفير عدد ضخم جداً من العناوين.

وجه المقارنة الإصدار الرابع (IPv4) الإصدار السادس (IPv6)
طول العنوان وطريقة التمثيل 32 bits (نظام عشري منقط) 128 bits (نظام ست عشري مقسم لـ 8 مجموعات كل منها 16 bits يفصل بينها :)
أنواع العناوين Unicast, Multicast, Broadcast Unicast, Anycast, Multicast (لا يوجد Broadcast ويُستعاض عنه بـ Multicast)
التقسيم والبادئة (Prefix) يُشار للبادئة بـ /nn يُشار للبادئة بـ /nnn (مثل /64)
طرق تخصيص العناوين Static أو Dynamic via DHCP Static، Static prefix with EUI-64، التخصيص التلقائي بدون حالة SLAAC، و Stateful DHCPv6
العناوين الخاصة (Private IP) مجالات RFC 1918 يدعمها وتسمى Unique-Local Address (fc00::/7) ولا تُوجه للإنترنت
عدد العناوين للمنفذ الواحد عنوان واحد فقط لكل Interface يمكن تخصيص أكثر من عنوان لنفس الـ Interface
سجل DNS المستخدم السجل A السجل AAAA
ترويسة الحزمة (IP Header) حجم متغير (20–60 bytes) بحسب الخيارات حجم ثابت (40 bytes) بدون خيارات، ويستخدم Extension Headers متسلسلة عبر حقل Next Header
بروتوكولات التوجيه RIPv2, OSPFv2, EIGRP, IS-IS, BGP-4 إصدارات محدثة: RIPng, OSPFv3 (OSPFv6), EIGRP for IPv6, MP-BGP
بروتوكول الإدارة والتحكم ICMP ICMPv6
اكتشاف العناوين الفيزيائية يستخدم بروتوكول ARP استُبدل ARP ببروتوكول NDP (Neighbor Discovery Protocol) مع ICMPv6
الحاجة إلى NAT أساسي للخروج للإنترنت بالعناوين الخاصة لا توجد حاجة لاستخدام NAT لوفرة العناوين العامة

③قواعد اختصار عناوين IPv6 والعناوين المحجوزة

  • قاعدتا اختصار عنوان IPv6:
    1. حذف الأصفار البادئة (Leading Zeros) من يسار كل مجموعة ست عشرية (مثلاً 0056 تصبح 56، و0000 تصبح 0).
    2. استبدال مجموعة أو سلسلة متتالية من مجموعات الأصفار بالرمز ::، ويُسمح باستخدام :: مرة واحدة فقط في العنوان الواحد (مثلاً FE00:0000:0000:0001:0000:0000:0000:0056 تختصر إلى FE00:0:0:1::56).
  • ترويسة IPv6 (المعيار RFC 2460): طولها ثابت (40 bytes)، وتستخدم حقل Next Header للإشارة إلى الترويسة الإضافية التالية (مثل Routing Extension Header ثم Fragmentation Extension Header) أو مباشرة إلى ترويسة الطبقة الرابعة (TCP أو UDP).
  • أنواع عناوين IPv6:
    • Unicast: لمنفذ (Interface) واحد محدد.
    • Anycast: لمجموعة منافذ (عقد)، وتُسلّم الحزمة إلى أقرب Interface يحمل هذا العنوان.
    • Multicast: لمجموعة منافذ، وتُسلّم الحزمة لكل Interface منتمٍ للمجموعة (ويقوم مقام الـ Broadcast).
  • جدول عناوين IPv6 الخاصة والمحجوزة:
العنوان (Address) الاستخدام (Usage)
::1/128 عنوان الحلقة الراجعة (Loopback address)
::/128 عنوان غير محدد (Unspecified address)
64:ff9b::/96 للترجمة بين IPv4 و IPv6
::ffff:0:0/96 عنوان IPv4 المضمن (IPv4-mapped address)
100::/64 كتلة عناوين للتجاهل (Discard-Only Address Block)
2001::/23 مخصص لبروتوكولات IETF
2001::/32 خاص ببروتوكول TEREDO
2001:2::/48 للمرجعية والاختبارات (Benchmarking)
2001:db8::/32 للتوثيق والأمثلة (Documentation)
2001:10::/28 خاص بـ ORCHID
2002::/16 تحويل 6to4
fc00::/7 عنوان محلي فريد (Unique-Local - يقابل Private IP)
fe80::/10 عنوان محلي للرابط (Link-Scoped Unicast / Link-Local)
