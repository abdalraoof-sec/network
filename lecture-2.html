①نموذج الطبقات السبع (OSI Model) ومقارنته مع TCP/IP

الهدف من نموذج OSI (Open System Interconnection) هو توحيد المعايير لضمان التوافق وإمكانية الاتصال بين الأنظمة والأجهزة المختلفة (علماً أن الأجهزة عملياً تعتمد نموذج TCP/IP).

رقم واسم طبقة OSI ما يقابلها في TCP/IP البروتوكولات والأمثلة الأجهزة العاملة فيها الوظيفة الأساسية
7. Application Application FTP, HTTP, SMTP Host, Servers التطبيقات التي يتفاعل معها المستخدم مباشرة.
6. Presentation Application — Host, Servers تصنيف البيانات وتنسيقها بحسب نوعها وتقديم خدمات لطبقة التطبيقات.
5. Session Application — Host, Servers إنشاء وإدارة جلسة الاتصال وتقديم خدمات لطبقة العرض.
4. Transport Transport TCP, UDP Stateful Firewalls بدء الاتصال، تسليم البيانات، كشف الأخطاء وإعادة الإرسال.
3. Network IP (Internet) IP Router العنونة المنطقية وتوجيه الحزم عبر الشبكات.
2. Data Link Link Ethernet, PPP, ATM Switches نقل البيانات بين جهازين متصلين، كشف الأخطاء، والتحكم بالتدفق.
1. Physical Link Ethernet (physical), Cable, Optical Repeater, Hub نقل البيانات على شكل بتات (Bits) عبر وسط الاتصال.

②شبكات الإيثرنت (Ethernet LAN - IEEE 802.3)

  • تنقسم طبقة الربط في معيار IEEE 802 إلى قسمين فرعيين:
    • MAC (Medium Access Control - IEEE 802.3): مسؤولة عن التحكم بالوصول للوسط والعنونة الفيزيائية.
    • LLC (Logical Link Control - IEEE 802.2): مسؤولة عن التحكم المنطقي بالربط مع الطبقة الأعلى.
  • معايير الطبقة الفيزيائية للإيثرنت (Ethernet Physical Layer Standards):

③أنماط الوصول للوسط (Half Duplex vs. Full Duplex)

  • نمط Half Duplex:
    • يتشارك الجهازان نفس قناة الإرسال والاستقبال (مثل Hub و Ethernet Bus)، ويشكلان Collision Domain واحدة.
    • يعتمد على خوارزمية CSMA/CD (Carrier Sense Multiple Access with Collision Detection): يتحسس الجهاز الوسط قبل الإرسال، وإذا أرسل جهازان معاً يحدث تصادم (Collision)، فترسل الأجهزة إشارة Jam وتتوقف عن الإرسال لفترة تأخير عشوائية تسمى Backoff Time.
  • نمط Full Duplex:
    • يخصص قناة مستقلة للإرسال وأخرى للاستقبال لكل منفذ (مثل Switch).
    • يسمح بالإرسال والاستقبال في نفس اللحظة، ويسمى Collision-Free ولا يحتاج إلى CSMA/CD.

④بنية فريم الإيثرنت (Ethernet Frame) وعناوين MAC

  • حقول Ethernet Frame:
    1. Preamble: للمزامنة بين المرسل والمستقبل.
    2. Start Frame Delimiter (SFD): يشير لبداية الفريم وقيمته دائماً 10101011.
    3. Destination Address: عنوان MAC للجهاز الهدف.
    4. Source Address: عنوان MAC للجهاز المرسل.
    5. Length / Type: يحدد نوع بروتوكول الطبقة الثالثة؛ القيمة 0800 تشير إلى IPv4، والقيمة 08DD تشير إلى IPv6.
    6. MAC Client Data and Pad: يحمل الحزمة المغلفة (مثل IP Packet)؛ أقل طول للفريم هو 64 bytes، وأعظم طول للحمولة يعتمد على نوع الفريم:
      • 1500 bytes للفريمات الأساسية.
      • 1504 bytes للفريمات الموسومة Q-tagged (802.1Q).
      • 1982 bytes للفريمات المغلفة.
    7. Frame Check Sequence (FCS) / Ethernet Trailer: يستخدمه المستقبل لكشف الأخطاء أثناء النقل.
  • خصائص وأنواع عناوين MAC (أو EUI):
    • طوله 48 بت (6 بايت) يُكتب بالنظام الست عشري بطريقتين: صيغة IEEE (01-23-45-67-89-ab) أو صيغة Cisco (0123.4567.89ab).
    • ينقسم عنوان Unicast MAC إلى: أول 24 بت (OUI) لمعرف الشركة المصنعة، وثاني 24 بت تعينها الشركة المصنعة للكرت.
    • أنواع عناوين MAC الثلاثة:
      • Unicast: يخص كرت شبكة لجهاز واحد محدد.
      • Broadcast: قيمته FFFF.FFFF.FFFF ويُرسل إلى جميع الأجهزة في نفس الـ Subnet.
      • Multicast: يُرسل إلى مجموعة محددة من الأجهزة.
    • أوامر إيجاد عنوان MAC: في نظام Windows نستخدم التعليمة ipconfig /all، وفي نظام Kali Linux نستخدم التعليمة ifconfig (يظهر بجانب حقل ether).

⑤آلية عمل السويتش (LAN Switch Operation)

  • جدول العناوين (MAC Address Table): يربط عنوان MAC لكل جهاز برقم المنفذ (Port) المتصل به على السويتش.
  • التعلم التلقائي (Dynamic MAC Address Learning): عندما يستقبل السويتش فريماً من منفذ ما، يقرأ Source MAC Address ويسجله في جدول الـ MAC مع رقم المنفذ القادم منه.
  • الفيضان (Flooding): إذا لم يجد السويتش الـ Destination MAC في جدوله (أو كان الفريم Broadcast)، يرسل الفريم إلى جميع المنافذ ما عدا المنفذ الذي أتى منه.
  • مجال البث (Ethernet Broadcast Domain / Subnet): جميع الأجهزة المتصلة بسويتش واحد (أو عدة سويتشات متصلة ببعضها بدون VLANs) تقع في Broadcast Domain واحد، ولا يعزل مجالات الـ Broadcast إلا جهاز من الطبقة الثالثة (Router).
