①مقارنة بروتوكولي الطبقة الرابعة: TCP مقابل UDP

وجه المقارنة بروتوكول TCP (Transmission Control Protocol) بروتوكول UDP (User Datagram Protocol)
نمط الاتصال موجه بالاتصال (Connection-Oriented) غير موجه بالاتصال (Connectionless)
تأسيس وإنهاء الاتصال يؤسس الاتصال عبر المصافحة الثلاثية (3-Way Handshake) وينهي الاتصال عبر أعلام FIN يرسل البيانات فوراً دون تأسيس أو إنهاء اتصال
الموثوقية وكشف الأخطاء موثوق جداً: يرقم الحزم، يؤكد الاستلام (ACK)، يرتب الحزم ويعيد إرسال المفقود غير موثوق: لا يؤكد الوصول ولا يعيد إرسال الحزم المفقودة
التحكم بالتدفق والسرعة يدعم التحكم بالتدفق (Flow Control / Windowing)، لكنه يسبب حملاً زائداً وتأخيراً خفيف وسريع جداً ولا يسبب تأخيراً
أبرز الاستخدامات التطبيقات الحساسة لفقدان البيانات (تصفح الويب، البريد، نقل الملفات) التطبيقات المتسامحة مع الفقدان والحساسة للتأخير (البث المرئي، الصوت VoIP، DNS)

②ترويسة TCP وآليات العمل (Handshake, Error Recovery, Flow Control)

  • حقول ترويسة TCP الأساسية:
    • Source & Destination Port: أرقام منافذ المرسل والمستقبل لتحديد التطبيق.
    • Sequence Number (32 bits): لترقيم وتتبع أجزاء البيانات المرسلة وإعادة ترتيبها عند المستقبل.
    • Acknowledgment Number (32 bits): يحمل الرقم التسلسلي للبيانات التالية المتوقع استلامها (مثلاً إرسال ACK = 400 يعني استلام البيانات حتى 399 بنجاح وانتظار البايت رقم 400).
    • Control Flags (9 bits): أهم الأعلام الستة:
      • SYN: لبدء الاتصال ومزامنة الأرقام التسلسلية (يُضبط في أول حزمة من كل جهاز).
      • ACK: لتأكيد وصول البيانات (قيمته 1 تعني أن الاتصال قائم).
      • FIN: لإنهاء الاتصال بشكل طبيعي بعد انتهاء إرسال البيانات.
      • RST: لقطع الاتصال بشكل فوري وإجباري.
      • PSH: لإجبار المستقبل على تمرير البيانات فوراً للتطبيق دون انتظار امتلاء الـ Buffer.
      • URG: يشير لوجود بيانات مستعجلة يحدد موقعها حقل Urgent Pointer (16 bits).
    • Window (16 bits): للتحكم بتدفق البيانات (Flow Control)؛ يحدد حجم البيانات التي يستطيع المستقبل استيعابها في الـ Buffer قبل إرسال ACK، وأقصى قيمة له هي 65,535 bytes (ولاستخدام حجم أكبر يُستخدم حقل Options).
    • Checksum: لفحص سلامة الترويسة والبيانات.
  • المصافحة الثلاثية لتأسيس اتصال TCP (Three-Way Handshake):
    1. الخطوة الأولى (SYN): يرسل العميل حزمة فيها SYN = 1 مع رقم تسلسلي ابتدائي عشوائي Seq = X.
    2. الخطوة الثانية (SYN-ACK): يرد السيرفر بحزمة فيها SYN = 1, ACK = 1 برقم تسلسلي خاص به Seq = Y ورقم تأكيد Ack = X + 1.
    3. الخطوة الثالثة (ACK): يرد العميل بحزمة تأكيد ACK = 1 تحمل الرقم Ack = Y + 1، فيبدأ تبادل البيانات.
  • إنهاء الاتصال في TCP: يتم عبر تبادل حزم تحمل العلم FIN وتأكيدها بـ ACK من الطرفين.

③ترويسة UDP

تتكون ترويسة UDP البسيطة من 4 حقول فقط:

  1. Source Port: رقم منفذ المرسل.
  2. Destination Port: رقم منفذ المستقبل.
  3. Length: طول الـ UDP Segment.
  4. Checksum: لاكتشاف الأخطاء.

④مفهوم المقبس (Socket) وتعدد الإرسال (Multiplexing) وأرقام المنافذ

  • المقبس (Socket): يتكون من 3 عناصر: (عنوان IP + رقم المنفذ Port + البروتوكول المستخدم TCP/UDP).
  • مبدأ Multiplexing: يسمح بتشغيل عدة تطبيقات على نفس الجهاز ونفس الاتصال والتمييز بينها عبر الـ Socket.
  • اختيار المنافذ: السيرفر ينصت على منفذ قياسي محجوز (أقل من 1024)، بينما يختار جهاز المستخدم منفذاً عشوائياً كـ Source Port أكبر من 1024.
  • جدول المنافذ القياسية (Ports) للبروتوكولات في TCP و UDP (مهم جداً للامتحان):
اسم التطبيق / البروتوكول رقم المنفذ (Port) البروتوكول (TCP / UDP) الوظيفة والملاحظات
FTP 21 TCP نقل الملفات عبر الشبكة.
SSH (Secure Shell) 22 TCP إدارة الأجهزة عن بُعد عبر قناة مشفرة آمنة.
Telnet 23 TCP إدارة الأجهزة عن بُعد عبر نص صريح (غير آمن).
SMTP 25 TCP إرسال رسائل البريد الإلكتروني (بينما للاستلام من السيرفر نستخدم POP3 أو IMAP).
DNS 53 UDP (ومذكور في جدول TCP/UDP) ترجمة أسماء النطاقات إلى عناوين IP.
DHCP 67 / 68 UDP تخصيص عناوين IP تلقائياً (67 للسيرفر، 68 للعميل).
HTTP 80 TCP تصفح الويب غير المشفر.
NTP (Network Time Protocol) 123 UDP مزامنة الوقت عبر الشبكة.
IMAP 143 TCP استلام وإدارة البريد الإلكتروني من السيرفر.
SNMP 161 / 162 UDP إدارة ومراقبة أجهزة الشبكة.
BGP 179 TCP تبادل معلومات التوجيه الخارجي عبر الإنترنت.
HTTPS 443 TCP تصفح الويب المشفر باستخدام بروتوكولي TLS / SSL.
IKEv1 / IKEv2 500 UDP تبادل المفاتيح في الشبكات الافتراضية الخاصة (VPN).
Syslog 514 UDP إرسال سجلات الأحداث والأنظمة.
DHCPv6 546 / 547 UDP تخصيص عناوين IPv6 تلقائياً.
RADIUS 1812 / 1813 UDP خدمات المصادقة والتحكم بالوصول المركزي.
IKEv1 / IKEv2 (NAT-T) 4500 UDP عبور حزم IKE عبر أجهزة NAT.

⑤الخادم الوكيل (Proxy Server)

  • يعمل في الطبقة السابعة (Application Layer) كوسيط في منتصف خط الاتصال بين المستخدم والإنترنت، حيث يطلب صفحات الويب نيابةً عن المستخدم ويخفي عنوان الـ IP الحقيقي للمستخدم عن الموقع الهدف.
  • الفوائد الأربعة لاستخدام Proxy Server:
    1. التحكم في استخدام الإنترنت: مراقبة وتقييد تصفح الموظفين أو الأطفال وحجب المواقع غير المرغوبة أثناء العمل.
    2. حماية الخصوصية: إخفاء وتغيير عنوان IP الخاص بصاحب الطلب الأصلي.
    3. تخطي الحجب: الوصول للمحتوى المحجوب من مزود الخدمة عبر طلب الصفحات بعنوان IP خاص بالبروكسي.
    4. تحسين السرعة وتقليل استهلاك الشبكة: التخزين المؤقت (Caching) لنسخ من المواقع الشائعة التي يطلبها الموظفون بكثرة.
